Poke API

API REST de pokémon construida con NestJS, Mongoose y MongoDB. Esto es un servicio HTTP: no hay interfaz de usuario, se consume desde tu cliente, tu terminal o tu aplicación.

Base URL https://poke-api-softdo.up.railway.app/api/v1

Todas las rutas están prefijadas con /api/v1. Las respuestas son JSON.

# Stack

  • NestJS
  • TypeScript
  • MongoDB
  • Mongoose
  • Railway

# Endpoints

Seis endpoints. Todos cuelgan de la base URL de arriba.

  • GET /api/v1/pokemon

    Lista los pokémon almacenados, ordenados de forma ascendente por número de pokédex.

    Query params (opcionales)
    ParamTipoDefaultDescripción
    limit number > 0 5 Cantidad de registros a devolver.
    offset number > 0 0 Registros a saltar (paginación).
    curl 
    # todos los pokémon con los valores por defecto
curl https://poke-api-softdo.up.railway.app/api/v1/pokemon

# página de 20 registros, saltando los 40 primeros
curl "https://poke-api-softdo.up.railway.app/api/v1/pokemon?limit=20&offset=40"
    200 OK 
    [
  { "_id": "6a8d1725c3e411bb29f3180c", "name": "bulbasaur", "numPokemon": 1 },
  { "_id": "6a8d1725c3e411bb29f3180d", "name": "ivysaur",   "numPokemon": 2 }
]
  • GET /api/v1/pokemon/:term

    Busca un pokémon por id de Mongo, por número de pokédex (numPokemon) o por nombre. El nombre no distingue mayúsculas. Devuelve 404 si no existe.

    curl 
    # por número de pokédex
curl https://poke-api-softdo.up.railway.app/api/v1/pokemon/4

# por nombre
curl https://poke-api-softdo.up.railway.app/api/v1/pokemon/charmander

# por id de Mongo
curl https://poke-api-softdo.up.railway.app/api/v1/pokemon/6a8d1725c3e411bb29f3180f
    200 OK 
    {
  "_id": "6a8d1725c3e411bb29f3180f",
  "name": "charmander",
  "numPokemon": 4
}
  • POST /api/v1/pokemon

    Crea un pokémon. name y numPokemon son obligatorios y únicos; el nombre se guarda en minúsculas. Cualquier propiedad extra en el body es rechazada.

    Body — application/json
    CampoTipoRequeridoReglas
    name string Sí Mínimo 1 carácter. Único.
    numPokemon number Sí Entero positivo, mínimo 1. Único.
    curl 
    curl -X POST https://poke-api-softdo.up.railway.app/api/v1/pokemon \
  -H "Content-Type: application/json" \
  -d '{ "name": "mewtwo", "numPokemon": 150 }'
  • PATCH /api/v1/pokemon/:term

    Actualiza un pokémon existente. El :term admite lo mismo que la búsqueda: id de Mongo, número de pokédex o nombre. El body es parcial: envía solo los campos que quieras cambiar.

    curl 
    curl -X PATCH https://poke-api-softdo.up.railway.app/api/v1/pokemon/charmander \
  -H "Content-Type: application/json" \
  -d '{ "name": "charmander-shiny" }'
  • DELETE /api/v1/pokemon/:id

    Elimina un pokémon. A diferencia de GET y PATCH, aquí solo se acepta el id de Mongo: cualquier otro valor devuelve 400 Bad Request. Responde { "status": "OK" }.

    curl 
    curl -X DELETE https://poke-api-softdo.up.railway.app/api/v1/pokemon/6a8d1725c3e411bb29f3180f
  • GET /api/v1/seed

    Puebla la base de datos con los primeros 100 pokémon consumidos desde la PokeAPI pública. Responde con el texto SEED EXECUTED.

    Operación destructiva: borra todos los registros existentes antes de insertar los nuevos.

    curl 
    curl https://poke-api-softdo.up.railway.app/api/v1/seed

# Cómo empezar

  1. Puebla la base de datos

    Si la base está vacía, llama una vez al seed para cargar los primeros 100 pokémon.

    curl 
    curl https://poke-api-softdo.up.railway.app/api/v1/seed

  2. Consulta el listado

    Pide los pokémon paginados con limit y offset.

    curl 
    curl "https://poke-api-softdo.up.railway.app/api/v1/pokemon?limit=10"

  3. Trabaja con un pokémon

    Búscalo por id, número o nombre y, desde ahí, créalo, actualízalo o elimínalo.

    curl 
    curl https://poke-api-softdo.up.railway.app/api/v1/pokemon/pikachu
